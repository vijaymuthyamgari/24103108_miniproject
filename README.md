# Bus Demand Analysis and Prediction Using R

## Project Overview
This project analyzes monthly bus passenger demand using R programming. It performs data preprocessing, exploratory data analysis, clustering, and machine learning-based demand prediction.

## Dataset
- Dataset: Chennai Hub (Dataset D)
- Data: Monthly booked passenger seats
- Time Period: January 2011 – January 2015

## Technologies Used
- R Programming
- dplyr
- ggplot2
- tidyr
- rpart
- randomForest

## Analysis Techniques
1. Data Cleaning and Preprocessing
2. Descriptive Statistics
3. Exploratory Data Analysis
4. Correlation Analysis
5. K-Means Clustering

## Machine Learning Models
1. Linear Regression
2. Decision Tree
3. Random Forest

## Model Evaluation
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)

## Project Structure
- bus_demand_prediction.R – Main R script
- Dataset_D_Chennai_Hub_combined_data.csv – Input dataset
- results_single_dataset/ – Generated results and graphs

## How to Run
1. Install R.
2. Install the required R packages.
3. Download the repository.
4. Update the dataset path in the R script.
5. Run the script in RStudio.

## Note
This project uses a limited monthly dataset. Predictions are experimental and intended for academic analysis.
